# 技术决策

1. **职责**：Java 提供全部业务 API；Next 仅负责页面及同源转发。Cookie 可以随图片请求发送，结果读取仍校验归属。
2. **事务**：提交事务中插入任务、关联和阶段，再发事件；AFTER_COMMIT 投递。监听器的拒绝落库必须 REQUIRES_NEW，避免在已提交事务里写入失效。
3. **容量**：两个线程（TASK_WORKERS 可设 1～4）、20 队列、AbortPolicy；拒绝持久化为失败，不用 CallerRunsPolicy 阻塞提交线程。
4. **状态**：任务与阶段边界在短事务中原子更新；条件 SQL 防止终态回退；version 防止前端旧响应覆盖。
5. **身份**：Alice/Bob 的 HttpOnly SameSite Cookie 演示，非生产认证；数据层始终按用户归属查询，文件不直接暴露目录。
6. **追踪**：Hooks + Context；快照与查询异常分开；只轮询未终结任务，使用 AbortController、会话代次和版本保护。
7. **文件**：只接收真实 JPEG/PNG，限制字节和像素；服务端 UUID 路径；Java2D 拼贴并原子公布 PNG。
8. **恢复**：浏览器刷新从后端恢复；进程重启不续跑，遗留任务明确标记 SERVER_RESTARTED，避免永久处理中。

9. **导入字符集**：SQL 本身为 UTF-8 不保证 mysql 客户端按 UTF-8 发送，种子显式 SET NAMES utf8mb4，表也固定 utf8mb4。HTTP smoke 对中文业务值进行断言。
10. **身份竞态**：初始化等待全部响应，所有身份结果带本地代次校验；切换有同步锁，卸载及切换取消旧请求。
11. **验证资源**：容器镜像与依赖复用现有 Docker；Docker 数据盘确认在 D 盘。额外界面 QA 复用本机已有 Edge/Playwright，独立 profile 和临时目录在 D 盘，不改用户浏览器会话。

12. **页面生命周期**：根布局中的用户身份持续保留；任务追踪只在模板详情、任务和历史页启用，回到广场停止并取消请求，返回相关页面重新读取服务端记录。
13. **有界请求**：查询 15 秒、上传/提交 60 秒；截止时间包含响应体读取，超时属于可恢复请求错误。调用方切换或卸载取消仍保持原有语义。
14. **HTTP 协议**：框架产生的 4xx 保留状态码和必要响应头，避免错误请求被误报为服务故障；未预期异常仍记录完整服务端日志。
15. **个人资料**：新增一对一 user_profile，稳定 Alice/Bob 身份与可编辑昵称分离。版本条件更新拒绝过期保存，头像复用有归属/真实图片校验的素材服务；不允许任意外部头像地址。单独资料状态更新不重建 TaskFeed。003 迁移可重复且不覆盖资料；退出仅清 Cookie，不删历史。未保存头像的文件回收仍是明确限制。
16. **基础账户**：按用户新增要求采用Java原生PBKDF2及MySQL随机会话，不引入JWT/Redis/第三方身份服务。保留原ID/归属，Demo仅限Alice/Bob；凭据与会话分表，退出撤销、登录错误次数持久化。基础登录不等于完整生产认证。回滚须保留Demo归属限制，不能将注册用户数据直接交给旧任意ID演示接口。
17. **真实浏览器**：可选QA镜像安装Linux Chromium与中文字体，仍在D盘Docker；Playwright Core固定1.64.1。只拦截指定任务GET模拟500，数据库和其他接口真实执行。HTTP主机名的randomUUID差异由getRandomValues解决，浏览器失败证据独立保留。手机是视口模拟，未冒充实体设备验收。
