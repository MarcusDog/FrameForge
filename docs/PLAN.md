## 技术与边界

Java 21、Spring Boot 3.5.16、MyBatis Starter 3.0.5、MySQL 8.4、Maven 3.9.14；Next.js 16.4.3、React 19.3.1、TypeScript 5.9.3。浅色蓝紫中文工作台，原生 CSS、fetch、Hooks。先核实发行包可取得性，发现版本不可用时依据实际注册表最小修正并记录。

Java 拥有全部业务与持久化；事务提交后有界执行器顺序处理；阶段短事务；终态保护；用户 Cookie；按任务独立轮询；Java2D 生成真实结果。无真实 AI、支付、生产认证、消息队列和自动续跑。
